# Plateforme d'invitations (nom de travail : Entrelacs)

Site d'invitations en français et arabe (RTL) : 8 modèles, éditeur en direct, export PDF A5 via l'impression du navigateur.

## Fichiers
- `index.html` : le site (modèles, éditeur, packs).
- `premium.html` : invitation animée d'exemple du pack Premium (musique, compte à rebours, Google Maps).
- `prestige.html` : invitation d'exemple du pack Prestige (lien et QR code par invité, galerie, espace organisateur via `prestige.html#gestion`).
- Le pack Starter n'a pas encore d'exemple.
- `PROJECT_STATUS.md` : suivi du projet, fonctions faites et à faire.

## Voir le site
Ouvrir `index.html` dans un navigateur, ou activer GitHub Pages (Settings > Pages).
